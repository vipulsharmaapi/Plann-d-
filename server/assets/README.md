The bundled 400, 600 and 800 static instances were generated from the official Manrope variable font using fontTools.varLib.instancer. font-metrics.json records advance widths from these instances for conservative preview line wrapping. These assets are server-only and are not served as public files.

Noto Sans Devanagari (400/800 static instances) and Noto Sans Symbols 2 provide Hindi and symbol fallback. Their OFL licenses are bundled separately. Sources: https://github.com/google/fonts/tree/main/ofl/notosansdevanagari and https://github.com/google/fonts/tree/main/ofl/notosanssymbols2 .
